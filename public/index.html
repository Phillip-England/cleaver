Cleaver

Portable file encryption for private handoffs
Self-contained binary

What Cleaver Does

Encrypt a file into a lock file, then unlock it later with the PIN and shard files.

Cleaver runs as a tiny web app served by one Go binary. The file work happens in your browser with Web Crypto: the app reads your selected file, creates encrypted output, and offers downloads for the lock file, shard files, and recovery note.

How It Works

  1. Choose a file. Cleaver reads it in the browser and never needs an upload endpoint.
  2. Enter a numeric PIN. The PIN selects and combines random shard files to derive the AES key.
  3. Download every output. Keep the .lock file, digit shard files, and recovery note.
  4. Decrypt later. Provide the lock file, the same PIN, and the shard files to recover the original file.

What To Keep

Store the encrypted .lock file separately from the shard files. Anyone decrypting needs the lock file, the PIN, and all ten shard files.

What Cleaver Cannot Do

Cleaver cannot recover a lost PIN, missing shard, corrupted lock file, or overwritten download. Treat the generated files as the only recovery material.

Deployment Shape

The Go binary embeds the files in public/ and serves them over HTTP. Build once, copy the binary, and run it with the address you want to expose.
